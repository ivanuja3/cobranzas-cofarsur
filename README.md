# Cobranzas Cofarsur

Dashboard interno de tesorería: compara pagos necesarios vs. cobranza semanal
para Cofarsur, con posición de caja del día y carga automática desde los
archivos de Pagos (FFN) y Cartera (Flujo de Fondos).

Los datos viven en Supabase (no en este repo). El login está restringido a
las personas invitadas por el equipo de tesorería.
